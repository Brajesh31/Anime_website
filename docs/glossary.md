# 📖 Glossary

| Term | Meaning in this repository |
|---|---|
| SPA | Single-page application; React updates route views within one HTML shell |
| Route | URL pattern mapped to a page component |
| Provider | External service supplying catalog, metadata, image, or media responses |
| Catalog | Searchable anime or manga records |
| Episode metadata | Information such as episode number, title, and ID |
| Playback source | Remote media URL returned in provider metadata |
| CORS | Browser policy governing cross-origin requests |
| Proxy rewrite | Host or dev-server rule forwarding a request to another destination |
| Blob URL | Temporary browser URL created from binary data |
| ReactPlayer | Dependency used to render media URLs |
| Vite | Development server and build tool |
| Demo capture | Genuine browser screenshot of the running application |
| Mockup | Conceptual illustration, not proof of implemented behavior |
