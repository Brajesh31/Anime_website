# 📝 Documentation maintenance

## Required updates
When a visible route changes, review the README route/feature matrix, relevant API notes, limitations, QA matrix, accessibility checklist, and demo captures if genuine screenshots can be recorded.

When dependencies, build scripts, or hosting rules change, update installation, development, deployment, and relevant architecture records.

## Accuracy rules
- Do not describe roadmap items as implemented.
- Do not call `anime.png` a website screenshot unless verified.
- Do not claim provider ownership, stability, licensing, or reliability without evidence.
- Do not claim accessibility or performance certification without performing audits.
- Do not invent stars, downloads, uptime, coverage, or contributor metrics.

## Review checklist
- [ ] Relative Markdown links resolve.
- [ ] Route paths match `src/App.jsx`.
- [ ] File paths match the repository tree.
- [ ] Known limitations remain current.
- [ ] Screenshots are genuine, current, and safe to publish.
