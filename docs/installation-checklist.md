# ✅ First-run checklist

- [ ] Install Node.js 18+ and npm.
- [ ] Clone the repository.
- [ ] Run `npm ci`.
- [ ] Run `npm run dev`.
- [ ] Open the Vite local URL.
- [ ] Load the home route.
- [ ] Open the anime route and inspect its remote request.
- [ ] Note that manga and light-novel areas are partial.
- [ ] Run `npm run lint`.
- [ ] Run `npm run build`.
- [ ] Read provider and content-rights notes before publishing.
