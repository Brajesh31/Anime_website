# Security Policy

Do not commit API keys, private provider credentials, user accounts, payment data, downloaded media, or hidden proxy secrets. Treat remote API responses as untrusted input and validate route parameters before requests.

Review third-party endpoints for HTTPS, CORS, rate limits, terms, content rights, and provider changes. Do not add code that bypasses authentication, paywalls, region controls, DRM, or anti-abuse systems.

Report vulnerabilities privately to Brajesh Kumar (`@brajesh31`) with the affected route, impact, reproduction steps, and redacted evidence.
