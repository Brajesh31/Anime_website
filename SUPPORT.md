# 🆘 Support and project help

## Where to ask
- **Bug:** Use the GitHub bug report issue form. Include route, reproduction steps, expected/actual behavior, and sanitized console/network evidence.
- **Feature idea:** Use the feature request form. Explain the user problem, not only the proposed UI.
- **Documentation correction:** Use the documentation issue form and identify the exact page/section.
- **Security concern:** Follow SECURITY.md and report privately. Do not publish credentials or exploit details.

## Before opening an issue
1. Read the README and FAQ.
2. Search existing issues for the same behavior.
3. Confirm whether the issue is reproducible.
4. Check if the failure is caused by an external provider.
5. Remove tokens, cookies, personal data, and unauthorized media from evidence.

## Useful diagnostic details
- Repository commit SHA.
- Browser and operating system.
- Route and sanitized identifier.
- Steps to reproduce.
- Expected and actual behavior.
- HTTP status and sanitized response shape.
- Whether the issue occurs locally, in production, or both.

## Project limitations
This is a prototype. The anime provider and manga proxy are external. Manga and light-novel experiences are incomplete. No account, watchlist, backend, or database exists. The project does not provide guaranteed media availability.

## Support boundaries
Do not use issues to request DRM bypass, paywall circumvention, authentication bypass, regional restriction evasion, or rate-limit evasion. External provider outages may be outside the maintainer's control.
