# Contributing

Contributions should improve the prototype without creating unauthorized media access or unstable provider dependencies.

- Use existing React, router, Tailwind, and component patterns.
- Handle loading, empty, error, and unavailable-provider states.
- Keep API URLs and provider assumptions centralized and documented.
- Do not commit secrets, tokens, user data, downloaded media, or build output.
- Run `npm run lint` and `npm run build` before opening a pull request.

Describe affected routes, third-party sources, licensing/terms review, responsive behavior, and validation in pull requests.
